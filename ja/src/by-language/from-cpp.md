# C++ から Rust へ

C++ を書いてきた人に向けた入口です。Rust の基礎を一から並べるのではなく、C++ で身につけた感覚を土台にして、Rust で変わるところだけを覚えていく、という進め方です。

## この構成について

C++ 経験者にとって、Rust の見た目の多くは馴染みのあるものです。変数、条件分岐やループ、関数、struct、テンプレート。低レイヤを制御する言語として、C++ と Rust は似た問題意識を持っています。「誰がメモリを持ち、いつ解放するか」という感覚は、C++ を書いてきた人には根付いているはずです。ここを一から丁寧に説明されても、退屈なだけで得るものは多くありません。

一方で、C++ と同じ感覚では書けないところがあります。

- 5 原則（rule of five）を手で守る代わりに、コンパイラが所有権の規則で強制する。コピーコンストラクタを書かなくても、二重解放はコンパイル時に弾かれる
- `std::move` は手動のキャスト。Rust ではムーブが既定で、moved-from な変数を使おうとするとコンパイルエラーになる
- C++ のコピーは暗黙。Rust では `.clone()` と書いて明示する
- ダングリング参照は C++ では未定義動作。Rust ではコンパイルエラーになる
- `nullptr` や `union` の代わりに、`Option` と `enum` で型に出す
- 例外の代わりに、`Result` と `?` でエラーを返す
- テンプレートは無制約。Rust のジェネリクスはトレイト境界で制約をつける
- `mutex` まわりのデータ競合は C++ では規律で防ぐ。Rust では `Send` / `Sync` で型が防ぐ

ここが、C++ から来た人がつまずきやすく、同時に Rust を Rust たらしめているところです。

だからこのセクションは、二段構えにします。

- 前半で、C++ とほぼそのまま通じるものを一気に確認します。「C++ のこれは Rust のこれ」という対応を確認しながら、既定の違いだけを拾います。
- 後半で、C++ と同じ感覚では書けないところを、一つずつじっくり見ます。「C++ ではこう、Rust ではこう、なぜそうなっているのか」を軸に、C++↔Rust のコードを並べて進みます。

後半の先頭には所有権とムーブを置きます。コピー・借用はすべてこの上に積み上がるので、ここを固めておくとあとの章で混乱しにくくなります。
