# 中級をふりかえる

中級では、初級で直した fmode を出発点に、章を重ねて列を一つずつ足してきました。

初級の fmode はパーミッション文字列とファイル名だけを出す小さなツールでした。それが `ls -al` と同じ列構成で出力できる形になっています。

中級を終えた状態のコードは、サンプルリポジトリの `ls-al` ブランチで確認できます。

https://github.com/shinagawa-web/rust-guide-sample-intermediate-low-level/tree/ls-al

## できるようになったこと

いまの fmode には、これだけのことができます。

- `cargo install` で自分のマシンに入れ、どこからでも呼び出せる
- GitHub Release に実行ファイルを添付して、他の人にも配れる
- `stat()` が返すフィールド（nlink・uid・gid・size・mtime）をすべて読み出せる
- Unix エポック秒を `Jul 10 17:05` の形式に変換できる
- `/etc/passwd` と `/etc/group` を読んで uid・gid を名前に変換できる
- size 列の幅を全エントリの最大桁数に合わせて揃えられる

## 身についた考え方

作る過程で、いくつかの Rust の考え方に触れました。

- `MetadataExt` を追加すると、ファイルの生のメタデータにアクセスできる。`mode()` もその一つにすぎない
- ファイルを `lines()` で1行ずつ取り出し、`split()` と `collect()` でフィールドに分解する。テキストファイルのパースはこの組み合わせで大半が書ける
- `get()` は `Option` を返す安全なアクセスで、パニックしない。取り出せたかどうかは `if let` で受け取る
- `struct` で1件分のデータをまとめ、`impl` に表示ロジックを置くと、`main` がシンプルになる
- `?` はエラーを呼び出し元へ渡す演算子で、`match` の入れ子を1文字に省ける

どれも「この列を追加したい」「ファイルから名前を引きたい」という目的から自然に出てきたものです。

## この先やってみたいこと

fmode は `ls -al` の出力形式に近づきましたが、本物の `ls` にはまだないものもあります。

- ドット始まりのファイルを除外する（`-a` で表示する）
- ファイル名でソートするだけでなく、サイズや更新日時でも並べ替える
- シンボリックリンクを矢印（`->`）付きで表示する
- 色を付けて、ディレクトリとファイルを見分けやすくする

また、fmode で使った「ファイルのメタデータを読んで処理する」という基本は、別のツールにもそのまま使えます。

- 指定したディレクトリ以下を再帰的に探索して、一定サイズ以上のファイルを列挙する
- 更新日時でファイルを分類して、古いものを整理する
- 特定の拡張子のファイルだけを集めて処理する

いずれも `fs::metadata()` と `fs::read_dir()` の組み合わせで骨格が作れます。中級でやってきたやり方をそのまま持ち出せます。
